# ⏰ Relógio em Java (Swing)

Este projeto é uma aplicação desenvolvida em Java com interface gráfica utilizando Swing. O sistema permite ao usuário visualizar a data e a hora atual por meio de uma interface simples e interativa.

## 🚀 Funcionalidades

- Exibição da data atual
- Exibição da hora (horas, minutos e segundos)
- Atualização das informações ao interagir com a interface
- Interface gráfica simples e intuitiva

## 🛠️ Tecnologias utilizadas

- Java
- Java Swing

## ▶️ Como executar o projeto

1. Clone o repositório:
git clone https://github.com/SeijiTnk1/relogio_swing.git

2. Abra o projeto em uma IDE:
- NetBeans
- IntelliJ IDEA
- Eclipse

3. Execute a classe principal do projeto

## 📚 Aprendizados

Este projeto foi desenvolvido para praticar:

- Manipulação de data e hora em Java
- Criação de interfaces gráficas com Swing
- Interação com eventos (cliques de botão)
- Exibição dinâmica de informações na interface

## 📌 Melhorias futuras
